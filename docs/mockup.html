Where the numbers come from

Each script overwrites one line in .claude/progress/<name>-<pid>.txt, such as 7 12 compiling assets. Its exit trap writes done 0, or done with the exit code.

No step count

A script that writes 0 0 gets a spinner and elapsed time instead of a bar, like sync-fixtures.sh here.

Narrow windows

Below the pane's width the terminal does not draw it, so the same mod writes the summary to the status line. /progress opens the pane at any width.
