Proposals

  1. Session pane

    The pane follows the session as well as the scripts: the tool Claude is running now, the last few it ran, its subagents, and how full the context and the five-hour limit are. Uses the tool.call, turn.start and turn.complete hooks, $.agent.list(), $.ui.view and $.session.usage().

  2. Rows that expand

    Each job row is a button. Press it to open the file path, pid, start time and exit code under the row. Uses Button with onPress.

  3. Dismiss

    Remove a stalled or finished row. The pane count says how many are hidden and brings them back. Uses $.store.

  4. Notifications

    A toast in the terminal when a job finishes, and a system notification when one fails or runs for more than 2 minutes. Uses $.ui.toast and $.ui.notify.

  5. Ask Claude

    A failed row sends its last output to Claude as a prompt, and the conversation carries on from there. Uses $.prompt.submit.

  6. Time remaining

    After three steps, the average time per step gives an estimate beside the elapsed time. No mod API call: the poll already sees every change.

  7. Last lines of output

    The details show the job's last few lines. Uses a second file per job, written by the helpers: <script>-<pid>.log.

  8. Stop

    End a running job from its row, after a confirmation that names the job and its pid. Uses $.process.run.

Not shown: shells Claude starts in the background. The tool.call hook sees one start, but the call returns at once, so the pane would not see it end. That needs testing before the pane promises it.

While a script runs, its file holds one line, <startedEpochSec> <step> <total> <label...>, in .claude/progress/<script>-<pid>.txt. When it finishes the line becomes <startedEpochSec> done <exitCode> <endedEpochSec>. A script with no step count writes a total of 0 and gets a spinner and elapsed time instead of a bar, like sync-fixtures.sh here. In a terminal narrower than 144 columns the pane does not open by itself, which leaves the status line, written at every width; /progress opens the pane at any width.
